# Archived Copilot Prompt Artifacts

These files are retained as historical work products from the earlier
`__copilot__/prompts/` workflow.

They are archived here rather than treated as canonical project
documentation because:

- they describe older prompting and scaffolding context;
- their instructions are partially stale relative to the current source; and
- agent startup should now begin from `project-steering/PROJECT_CONTEXT.md`
  plus the code-adjacent docs in `web/docs/`, `api/docs/`, and `infra/docs/`.

Keep these only for historical reference or migration context.
