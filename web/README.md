# Program Rig Web

This package is the user-facing workout runner built with Next.js App Router
and static export output.

Start here:

- [`docs/README.md`](./docs/README.md) - documentation index
- [`app/page.tsx`](./app/page.tsx) - route entry point
- [`components/features/ProgramExecutor.tsx`](./components/features/ProgramExecutor.tsx) - main runtime orchestration

Useful commands:

```bash
npm run dev
npm run lint
npm run build:dev
npm run build:prod
```

Local development runs on `http://localhost:3030`.
